# Legacy identifier and save safety

The rebrand does not bump the generator or save schema. `jade-garden-tiles-save-v5` and its backup/legacy keys remain authoritative, preserving attempts, progression, stars, currency, boosters, achievements, settings, tile style and local records. The internal `garden-player` ID remains stable; its legacy default display name migrates from “Garden Player” to “Player.”

The Android application ID and Java package remain unchanged, preserving update compatibility and the same application sandbox.
